# mailfire artwork

The mailfire logo: an orange flame with a cut-out envelope, next to the word "mailfire".

- Flame color: `#F0531C`
- Wordmark: Space Grotesk Bold, letter spacing −0.03em; `#F4F4F5` on dark, `#1C1D21` on light
- Dark tile: `#16171A`

## Files

| File | Use |
|------|-----|
| `banner-black.png` | README banner on black, 1280×400 (same as `docs/static/images/logo.png`) |
| `social-preview-black.png` | GitHub social preview on black, 1280×640 |
| `logo-on-white.png` | Logo on white, 1280×400 |
| `logo-transparent-dark-text.png` | Logo on transparent background for light surfaces, 1120×280 |
| `logo-transparent-light-text.png` | Logo on transparent background for dark surfaces, 1120×280 |
| `mark.svg`, `mark-<size>.png` | Flame only, orange, transparent background; the envelope is cut out |
| `mark-black.svg`, `mark-black-<size>.png` | Flame only, black, for single-color use |
| `mark-white.svg`, `mark-white-<size>.png` | Flame only, white, for single-color use on dark backgrounds |
| `app-icon.svg`, `app-icon-<size>.png` | App icon: white flame on an orange rounded tile |
| `app-icon-dark.svg`, `app-icon-dark-<size>.png` | App icon: orange flame on a dark gray tile |
| `app-icon-black.svg`, `app-icon-black-<size>.png` | App icon: orange flame on a black tile |
| `favicon.ico` | Favicon with 16, 32, 64 and 256 px, from `app-icon` |

PNG sizes: 16, 32, 64, 128, 256, 512 and 1024 px.

The SVGs contain only shapes, no text, so they render the same everywhere. The wordmark exists only in the PNGs, because it is set in Space Grotesk, a web font. Edit the SVGs and export the PNGs again from them; the PNGs were rendered with headless Chrome.
